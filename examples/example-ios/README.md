# example-ios

Minimal iOS example showing Screeb SDK integration.

> The iOS SDK is closed source. See [developers.screeb.app](https://developers.screeb.app) for the full documentation.

## Requirements

- iOS 13+
- Xcode 14+
- Swift Package Manager

## Setup

1. In Xcode → File → Add Package Dependencies
2. Enter: `https://github.com/ScreebApp/sdk-ios` (private)
3. Add `Screeb` to your target
