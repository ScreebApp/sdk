# `@screeb/sdk-svelte-example`

Screeb's example app for Svelte sdk.

> Documentation: [developers.screeb.app/sdk-svelte/install](https://developers.screeb.app/sdk-svelte/install)

## Get started

### Before get started

This package requires the installation of the whole mono-repository.

See [getting started guide](../../README.md#get-started) for more information.

### Getting set up

Just run

```bash
npm start
```

Then go to [http://localhost:5173/](http://localhost:5173/)
